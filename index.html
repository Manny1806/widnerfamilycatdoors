Product Description

Our patented cat door window inserts are engineered for smooth sliding and secure closure, built to fit into sliding (horizontal) and vertical/sash windows. No cutting, no drilling — it installs in the window opening itself, so there's no permanent change to your home. Easy to install, and even easier to remove.

Sizing & Fit

Both versions adjust to fit windows between 16 and 36 inches — vertical windows adjust by width, sliding windows adjust by height. The cat passage opening is 7 inches wide by 7¾ inches tall on every door.

Window bigger than 36 inches? 8-inch extension panels are sold separately (1 panel $16, 2 panels $32, 3 panels $48) to extend the fit range — see the extension panel installation video. Window smaller than 23 inches? A panel segment is removed during install (see the installation videos below). If you're not sure your window will work, message the shop before you buy.

Frequently Asked Questions

Can you put a cat door in a window?

Yes. Instead of cutting a hole in a wall or exterior door, the insert fits directly into your window opening, replacing the need for a permanent cut-through.

Do I need to drill or cut anything to install it?

No. The insert slides into the window opening and is secured without tools, drilling, or hardware. Nothing is permanently altered.

Will this work for a catio?

Yes — it can give your cat window access between your home and an outdoor catio without needing a permanent structural opening.

I rent my home — is this a safe option?

Yes. Because nothing is drilled, cut, or permanently attached, you can remove it and restore the window to its original state, which makes it a renter- and apartment-friendly way to add a cat door.

Can I take it with me if I move?

Yes. The insert isn't fixed to the window — you can remove it and reinstall it in a new home's window.

Does it work with sliding and vertical windows?

Yes, it's designed for both horizontal sliding windows and vertical (single-hung/double-hung) windows. See the sliding window and vertical window pages for installation details specific to each.

How much does it cost?

$100 per door, fits windows 16–36 inches. If your window is larger, 8-inch extension panels are available for $16–$48. See our Etsy shop for current pricing and options.
